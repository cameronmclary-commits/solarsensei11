WHAT'S INSPECTED

installs inspected Independently

1. Panel Condition Assessment

Visual inspection of every panel in the array — verifying correct placement, secure mounting, and absence of shipping or installation damage. Where thermal imaging is used, the report confirms panels are operating within expected thermal ranges.

2. Inverter Assessment

Inverter model, capacity, firmware version, and current operating status. For systems with monitoring platforms, we pull early generation data and compare actual output against expected output for the system size and location — confirming the system is performing as designed.

3. Mounting Hardware & Structural Assessment

Verification of mounting rails, clamps, and roof penetration points — confirming correct installation, proper sealing, and compliance with the manufacturer's specifications and Australian standards.

4. Electrical Wiring & Connection Assessment

Inspection of DC string cables, MC4 connectors, DC isolators, AC isolators, and the connection between the inverter and the main switchboard — verifying correct wiring, secure connections, and proper labelling throughout.

5. Generation Performance Analysis

Comparison of early generation data against the expected output for the system's rated capacity, location, and orientation. We confirm the system is producing as designed and provide a clear performance score that's meaningful to non-technical readers.

6. Compliance Status

Assessment of whether the installation meets current Australian standards, including AS/NZS 5033 for solar panel installation and the relevant inverter connection requirements. The report confirms compliance and notes any areas where the installation exceeds minimum requirements.
